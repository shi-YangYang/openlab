# 项目路线图

本路线图为 openlab 的高层规划，具体功能以各 Spec 为准。路线图会随需求变化持续更新。

## Phase 0 — 项目初始化

- 建立项目目录结构与基础文档。
- 确定技术栈与开发规范。
- 搭建前后端项目骨架。

## Phase 1 — 基础架构

- 后端基础框架与数据模型。
- 前端基础框架与页面骨架。
- 用户与权限体系（如适用）。

## Phase 2 — 文献挖掘（当前优先级最高）

- 文献搜索与下载（arXiv）：spec-001。
- 文献解析、清洗与存储。
- 论文自动分析（基于 LLM）。

## Phase 3 — 创新点与假设生成

- 自动设计论文创新点。
- 基于文献与数据生成科研假设。
- 假设的来源引用与可追溯性。

## Phase 4 — 实验设计

- 实验方案的结构化建模。
- 根据假设自动生成实验设计。
- 实验计划的可视化与编辑。

## Phase 5 — SSH 服务器部署自动化

- SSH 服务器连接与凭据管理（通过 PowerShell 内置 SSH）。
- 实验环境自动化部署（GPU 服务器）。
- 服务器监控（GPU/进程/资源）。
- 实验自动执行与结果回传。

## Phase 6 — 集成与发布

- 全流程串联：文献 → 假设 → 实验设计 → 部署执行。
- 测试、文档与开源发布准备。
