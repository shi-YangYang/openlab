# spec-009 服务器详情页与监控可视化决策

## 决策标题

确定服务器二级详情页（spec-009）的监控可视化、部署增强与环境配置方式。

## 元信息

- **日期**：2026-08-24
- **状态**：accepted
- **决策者**：用户
- **关联 Spec**：spec-009-server-detail

## 决策

1. **详情页**：一级页每服务器四个操作（编辑/详情/删除/测试），点击详情进入二级详情页，顶部面包屑「服务器列表 / 服务器名」。
2. **监控可视化**：用 AntD 表格/进度条/卡片展示 GPU/CPU/内存/磁盘（结构化解析），原始文本作为回退。
3. **部署增强**：本地路径支持手动输入 + 文件/文件夹选择器（浏览器选择 → 上传）。
4. **环境配置**：预设命令（pip install/conda 等）+ 自定义命令执行，两者都要（Web 终端留待 spec-010）。

## 理由

- 二级详情页是部署/监控/环境配置等功能区的统一承载。
- 结构化监控比原始文本更直观；AntD 组件即可，无需引入图表库。
- 文件选择器弥补手动填路径的不便；环境配置补上部署后缺少的一环。

## 影响与后果

- 后端新增结构化监控解析、命令执行、文件上传（multipart）接口。
- 前端新增服务器详情页与功能区。
- 无新依赖（AntD 组件 + 浏览器原生文件选择）。
