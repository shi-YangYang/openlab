# spec-010 Agent 核心决策

## 决策标题

确定 Agent 核心（spec-010）的工具范围、交互方式与实现框架。

## 元信息

- **日期**：2026-08-24
- **状态**：accepted
- **决策者**：用户
- **关联 Spec**：spec-010-agent-core

## 决策

1. **工具范围**：暴露全部现有能力（搜索/下载/分析/综述/创新点/实验设计/服务器/部署/执行/监控）。
2. **交互方式**：任务式（给目标自主执行）+ 对话式，两者都要。
3. **实现框架**：LangChain tool-calling agent（复用现有 ChatOpenAI + OpenAI 兼容 LLM）。

## 理由

- 项目定位是「Agent 框架」，核心价值在「LLM 能自主调用工具把科研流程串起来」，而非纯 UI。
- 后端能力（spec-001~009 接口）已具备，封装为工具即可让 agent 编排执行。
- LangChain 工具调用（function calling）与现有 LangChain 依赖一致，实现最简。

## 影响与后果

- 新增 agent 工具封装、agent 循环、会话管理、agent API。
- 前端新增「Agent」页面（对话 + 工具调用执行日志 + 进度）。
- 安全注意：agent 可执行命令/部署，属高权限操作，后续需考虑确认机制。
