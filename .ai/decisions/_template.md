# 决策记录模板

## 决策标题

一句话概括决策内容。

## 元信息

- **日期**：YYYY-MM-DD
- **状态**：`proposed` / `accepted` / `superseded`
- **决策者**：协调开发 Agent / 用户
- **关联 Spec**：（如有）

## 背景与问题

描述面临的决策问题与上下文。

## 备选方案

- 方案 A：...（优点 / 缺点）
- 方案 B：...（优点 / 缺点）

## 决策

明确写出最终选择的方案。

## 理由

说明选择该方案的原因。

## 影响与后果

说明该决策带来的影响、约束与后续需要注意的事项。
