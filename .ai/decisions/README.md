# 决策记录目录

本目录存放项目中的重要决策记录（ADR，Architecture/重要 Decision Records）。

## 记录规则

- 每个重要决策单独一个文件。
- 命名建议：`YYYY-MM-DD-简短描述.md`（如 `2026-08-24-choose-fastapi.md`）。
- 记录内容：决策内容、背景、备选方案、理由与影响。
- 模板见 `_template.md`。

## 什么算重要决策

- 技术栈、架构、数据模型等方向性选择。
- 需求范围、业务规则等影响后续开发的决定。
- 对话中达成的、会影响后续开发的重要结论。

## 约束

- 凡存在不明确之处，禁止猜测，先向协调开发 Agent（或用户）确认。
- 决策一经记录，后续 Spec 与开发需与之一致；如变更需新增决策记录说明。
