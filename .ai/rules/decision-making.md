# 决策规则

约束项目中所有 Agent 的决策行为。

## 核心原则

- 凡存在不明确之处，禁止在缺少依据的情况下猜测。
- 需要决策时，由协调开发 Agent 向用户确认；子 Agent 将问题返回协调开发 Agent。
- 子 Agent 不得绕过协调开发 Agent 直接替用户做项目决策。

## 决策记录

- 重要决策记录到 `.ai/decisions/`，模板见 `.ai/decisions/_template.md`。
- 重要对话结论、需求变化等影响后续开发的信息也须留痕，不能只保存在对话上下文。

## 决策一致性

- 决策一经记录，后续 Spec 与开发需与之一致。
- 如需变更，新增决策记录说明变更原因与影响，不得静默更改。
