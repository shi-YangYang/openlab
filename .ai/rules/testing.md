# 测试规则

约束测试与验收行为。

## 测试要求

- 测试文件、验收脚本统一存放在 `tests/` 目录。
- 实施完成后应运行相关测试，确保代码可用。
- 验收 Agent 依据 Spec 的验收标准（AC）逐条判定，并运行测试/验收脚本。

## 验收标准

- 每条验收标准应可判定（PASS/FAIL）。
- 验收 Agent 独立执行验收，不依赖实施 Agent 的自述结论。

## 结论

- 验收结论分为 `PASS` / `FAIL` / `BLOCKED`。
- `FAIL` 进入返工流程，`BLOCKED` 返回协调开发 Agent 处理。

## 约束

- 实施 Agent 不需要验收；验收由独立的验收 Agent 完成。
- 不假定具体测试框架，以项目实际采用的框架为准（见 `constitution/tech-stack.md`）。
