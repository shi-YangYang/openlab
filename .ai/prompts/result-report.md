# 结果报告模板

> 子 Agent（实施/验收）完成任务后，向协调开发 Agent 返回结果时使用。

## 结果报告

- **角色**：实施 Agent / 验收 Agent
- **任务名称 / Spec 编号**：
- **结论**：完成 / 未完成 / PASS / FAIL / BLOCKED

### 完成内容

- 已实现/已检查的内容清单。

### 变更文件

- 新增/修改/删除的文件列表（实施 Agent 填写）。

### 未完成或失败项

- 未完成内容或未满足的验收标准（含 AC 编号）。

### 阻塞与风险

- 需协调开发 Agent 或用户处理的阻塞项。

### 测试情况

- 运行了哪些测试/验收脚本，结果如何。

### 备注

- 其他需要说明的事项。
