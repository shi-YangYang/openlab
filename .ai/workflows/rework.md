# 返工工作流

描述验收失败后的返工流程。

## 触发条件

验收 Agent 返回 `FAIL`，即存在不满足验收标准的项。

## 流程

1. 协调开发 Agent 读取验收报告，明确不满足项。
2. 整理返工任务清单（针对失败项，含验收标准的引用）。
3. 创建新的实施 Agent 进行返工，传入：
   - 原 Spec 与验收标准。
   - 上一轮验收报告（失败项）。
   - 必要的实施报告与返工记录。
4. 返工完成后，创建新的验收 Agent 重新验收。

## 约束

- 返工应聚焦失败项，避免无依据的大范围返工。
- 不得跳过已有验收结果。
- 每轮返工与验收均需留痕（写入 `acceptance.md` 的验收记录表）。
- 禁止重复创建无依据的实施/验收 Agent。
