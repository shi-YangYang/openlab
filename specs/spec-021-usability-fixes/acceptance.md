# Spec 021 验收清单

## 准备

1. 后端、前端启动；无 Semantic Scholar API Key（默认态）。
2. 搜索页可正常访问。

## AC-1 限流应对（FR-1 ~ FR-4）

- [ ] 选择含 Semantic Scholar 的平台搜索：若遇官方限流，接口内部自动重试；最终成功时结果正常返回，无需用户干预。
- [ ] 重试仍失败时：该平台降级为外链跳转，且提示行附带原因文案「官方接口限流(429)，已自动重试仍未恢复」（或其它具体原因），不再只有笼统的失败。
- [ ] 登录类平台（百度/知网）的 need_login / 过期提示行为不变。
- [ ] 在 `.env` 配置 `SEMANTIC_SCHOLAR_API_KEY` 后重启，抓包或日志确认请求带 `x-api-key` 头。
- [ ] `.env.example` 含该变量说明。

## AC-2 Agent 输入框（FR-5）

- [ ] 输入框初始约 4 行高；粘贴长文本可看到内容，超过自动长高至多 10 行后内部滚动。

## AC-3 思考强度输入宽度（FR-6）

- [ ] 给某模型填入 5 个以上推理强度值：输入框横向伸展承载（最小约 300px 且随窗口弹性），不出现值换行导致的行高增加。
- [ ] 整页高度保持稳定；窄窗口下仍不挤压删除按钮。

## AC-4 搜索表单文案（FR-7）

- [ ] 两枚模式按钮显示「直接搜索」「AI 智能搜索」。
- [ ] 鼠标悬浮任一按钮出现 Tooltip，解释两种模式差异（AI 模式会先由 LLM 改写检索式）。
- [ ] keyword 模式输入框 label 为「搜索关键词」、占位为直白示例；topic 模式 label 为「研究主题描述」、占位说明会被 AI 改写为检索式。

## 回归

- [ ] arXiv / 百度学术 / 知网搜索与登录态流程不受影响；搜索历史回填、论文下载分析照常。
- [ ] 后端 `pytest tests -q` 全部通过；前端 `npm run build` 通过。
