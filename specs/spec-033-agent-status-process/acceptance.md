# 验收标准：spec-033-agent-status-process

## 僵尸状态

- AC-1：后端启动后，所有会话 `running=0`、`status=''`（直接改 DB 残留数据再重启验证）。

## 回合结构与折叠

- AC-2：实时多轮运行（文本→工具→文本→工具→最终文本）渲染为：多个 intermediate 回合 + 独立的最终回复；最终回复不再包含中间说明文字。
- AC-3：运行中过程内容展开可见且指示器内联其中；done 后自动收进「思考与过程 · N 步」，点击可展开；手动展开后不再被强制收起。
- AC-4：`pending_approval` 暂停时过程内容保持展开并显示「等待你的确认」；拒绝后已产出内容保留。

## 内联指示器

- AC-5：指示器仅在运行中显示：思考阶段 `思考中 · Ns`；工具执行阶段 `执行中：<tool> · Ns`（秒数跳动）；完成/错误/中断立即消失；列表底部不再有独立状态行。
- AC-6：首轮未产出内容时指示器出现在空区域顶部，不悬空错位。

## 历史还原

- AC-7：重新打开刚完成的多轮会话：中间说明文字 + 工具调用卡片完整还原进折叠框，最终回复正常渲染（toolbar 的模型名/时间正确）。
- AC-8：旧会话（无 intermediate/toolCalls 字段）打开不报错，按现状逐条渲染。

## 工程

- AC-9：`normalize_history` 单测覆盖：中间 AI 消息判定、toolCalls 重建、空文本带工具 AI 消息不丢弃、旧数据兼容；pytest 全量通过。
- AC-10：`npm run build` 通过。
- AC-11：回归：spec-030 toolbar、spec-032 权限与审批、附件上传、上下文压缩、停止中断均正常。
