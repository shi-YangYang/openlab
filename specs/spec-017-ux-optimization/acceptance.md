# Spec 017 验收清单

## 准备

1. 后端启动、前端启动。
2. 论文库有若干已下载论文；已配置一台 SSH 服务器。
3. LLM 已配置（用于分析/综述/创新点/实验方案生成）。

## AC-1 服务器详情折叠（FR-1）

- [ ] 进入某服务器详情页，监控/部署/环境配置/终端四个区块默认全部折叠。
- [ ] 点击任一区块标题可展开查看其内容。
- [ ] 展开后内容与原功能一致（监控可刷新、部署可 clone/上传、环境配置可执行命令、终端可连接）。
- [ ] 可同时展开多个区块，互不影响。

## AC-2 论文分析二级页面（FR-2 / FR-6）

- [ ] 在论文库点击某论文「分析」，跳转到 `/papers/{arxivId}/analysis`。
- [ ] 顶部面包屑显示「论文库 / {论文标题}」，「论文库」可点击返回 `/library`。
- [ ] 页面可切换语言、触发分析、轮询展示结果、导出 Markdown（功能与原弹窗一致）。
- [ ] 直接访问该 URL 可正常渲染（刷新不丢状态）。

## AC-3 对比综述二级页面（FR-3 / FR-6）

- [ ] 在论文库选择 ≥2 篇后点「对比综述」，跳转 `/papers/review?ids=...`。
- [ ] 面包屑「论文库 / 对比综述」；生成与展示逻辑与原弹窗一致。

## AC-4 生成创新点二级页面（FR-4 / FR-6）

- [ ] 选 ≥1 篇后点「生成创新点」，跳转 `/papers/innovation?ids=...`。
- [ ] 面包屑「论文库 / 生成创新点」；数量/语言/生成/导出逻辑与原弹窗一致。

## AC-5 生成实验方案二级页面（FR-5 / FR-6）

- [ ] 选 ≥1 篇后点「生成实验方案」，跳转 `/papers/experiment?ids=...`，面包屑「论文库 / 生成实验方案」。
- [ ] 在创新点历史点某条「实验方案」，跳转 `/papers/experiment?innovation_id=...`，面包屑「创新点历史 / 生成实验方案」。
- [ ] 生成与展示逻辑与原弹窗一致。

## AC-6 浏览器标题（FR-7）

- [ ] 浏览器标签标题显示为「openlab科研agent」。

## 回归

- [ ] 搜索、论文库、历史（搜索/创新点/实验方案）、服务器管理、Agent、设置均正常。
- [ ] 创新点历史「查看」/「来源」、实验方案历史「查看」等只读弹窗仍正常。
- [ ] 前端 `npm run build` 通过。
- [ ] 后端 `pytest tests -q` 全部通过。
