# spec-011 汇总：Agent 会话持久化与 UI 优化

> 本文档汇总 spec-011 从需求、实施到验收的全部结论。最终状态：**已完成（completed）**。

- **Spec 编号**：`spec-011-agent-session-ui`

## 背景与目标

spec-010 实现了 Agent 核心，但会话仅内存（重启即丢）、无会话列表/管理，且 LLM 回复 Markdown 未渲染、UI 简陋。spec-011 补齐会话持久化、管理与渲染体验。

## 功能需求清单（FR-1 ~ FR-7，全部完成）

- FR-1：会话持久化到 SQLite（重启保留）。
- FR-2：会话列表（侧边栏，倒序）。
- FR-3：新建会话。
- FR-4：删除会话（带确认）。
- FR-5：会话标题自动生成 + 手动重命名。
- FR-6：LLM 回复 Markdown 渲染（react-markdown + remark-gfm，防 XSS）。
- FR-7：对话框 UI 优化（会话侧边栏 + 聊天气泡）。

非功能：NFR-1 密钥安全；NFR-2 防 XSS。

## 验收结果

验收标准 AC-1 ~ AC-8 **全部 PASS**（轮次 1）。`pytest` 160 passed，前端 build 通过。

## 验收后追加的修复

1. 进入 Agent 页自动选中最近会话 / 无则新建，避免「无会话也能聊天」的不一致。
2. 聊天框高度改为 `calc(100vh - 240px)` 响应式。
3. 删除 assistant 空气泡里的「（等待危险操作确认…）」占位，避免「思考提示重复」。
4. 会话标题与用户消息在 agent 循环**之前**落库，刷新不再丢聊天记录。
5. 发送时若无会话先创建并即时加入侧边栏 + 乐观更新标题，会话即时可见。
6. 新增持久化 `running` 状态 + 前端轮询，刷新后仍能显示「Agent 正在执行…」并在完成后自动加载结果。

## 使用方式

- 顶部「Agent」页：左侧会话列表（新建/重命名/删除），右侧对话区（Markdown 渲染 + 工具调用日志 + 危险命令确认），发送消息后 agent 自主执行。
