# Spec 023 验收清单

## 准备

1. 后端、前端启动；已配置一台可连通的 SSH 服务器（有 Python 环境）。
2. 已有一条实验方案记录（spec-007 生成或手工入库）。
3. 远端准备一个最小训练脚本（如 `train.py`：循环 print epoch/loss 并 sleep），用于真实验证。

## AC-1 创建与人工执行（FR-1 / FR-2 / FR-10）

- [ ] 实验方案历史页点「执行」，面板内选择服务器并可测试连接。
- [ ] 四步骤命令可见且可编辑（sync_code 可选 clone 或上传）。
- [ ] 点「开始执行」后步骤按序推进，每步实时输出日志；全部成功后 run 状态为 running（训练已拉起）。
- [ ] 每步可单独跳过或替换为自定义命令后重跑。

## AC-2 日志流式展示（FR-3 / FR-11）

- [ ] 训练输出的每一行日志在面板实时滚动出现，无需手动刷新。
- [ ] 日志区自动滚底；向上滚动查看历史时不会强制拉回底部（暂停滚动生效）。
- [ ] 关键词过滤输入高亮匹配行并显示命中数。

## AC-3 停止与进程管理（FR-5）

- [ ] 点「停止任务」后远端训练进程被终止（`ps` 确认 PID 不存在），run 状态 stopped。
- [ ] 停止后面板不再继续推日志。

## AC-4 失败兜底（FR-4）

- [ ] 人为让某步失败（如错误命令）：自动重试 1 次后 run 进入 paused，时间线该步标记失败原因。
- [ ] paused 态提供「改命令重试」：修正命令后该步成功，流水线从断点继续。
- [ ] 「跳过此步」生效，流水线进入下一步。

## AC-5 Agent 主导模式（FR-8 / FR-9）

- [ ] 对 agent 说"在 xx 服务器上运行实验方案 yy"：出现危险操作审批，批准后 run 被创建并自动推进到 training 启动成功。
- [ ] agent 最终回复包含 run_id 与进展摘要（含 tail 日志片段）；后续追问进度时能给出新日志。
- [ ] 运行中途对 agent 说停止，对应远端进程被终止。

## AC-6 历史与回放（FR-13）

- [ ] runs 列表展示状态/耗时/错误；点击载入详情，已结束的 run 可完整回放日志。

## 回归

- [ ] 既有的 clone/SFTP/exec/monitor/terminal 功能不受影响（共用 ssh.py 未破坏签名）。
- [ ] agent 既有工具与会话功能正常；实验方案生成与历史不受影响。
- [ ] 后端 `pytest tests -q` 全部通过；前端 `npm run build` 通过。
