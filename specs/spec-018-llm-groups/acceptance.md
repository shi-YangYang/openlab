# Spec 018 验收清单

## 准备

1. 后端启动、前端启动。
2. 已有一份旧的扁平 `data/llm_config.json`（用于验证迁移）或空配置。
3. 一个 OpenAI 兼容平台的可测试凭据（用于获取模型/测试连接/真实 agent 对话）。

## AC-1 配置组管理（FR-1 / FR-3 / FR-6）

- [ ] 设置页 LLM 配置显示为「配置组」列表，可新增/编辑/删除组。
- [ ] 每组可编辑：name、base_url、api_key、模型列表（可多选/自定义）、默认模型、思考强度。
- [ ] 可切换「当前使用」组（active_group），保存后 `GET /api/llm/config` 返回正确的 active_group。
- [ ] 每组「获取模型」能拉取该平台模型列表填入 models；失败给出明确提示。
- [ ] 每组「连通性测试」用该组 base_url/api_key/模型测试成功/失败。
- [ ] 旧扁平配置首次加载后自动迁移为单个「默认」组，字段不丢。

## AC-2 有效配置回落（FR-2）

- [ ] 分析/创新点/实验方案/主题搜索等仍用当前组的默认模型正常工作（无回归）。

## AC-3 agent 模型与强度选择（FR-4 / FR-7）

- [ ] agent 页顶部有「模型」下拉（来自当前组 models）与「思考强度」下拉。
- [ ] 选择模型/强度后发送消息，agent 使用所选模型与强度（可观察调用或后端日志/结果）。
- [ ] 切换会话时选择保持/重置行为合理（默认回落当前组默认值）。
- [ ] 未选时使用当前组默认模型与默认思考强度。

## AC-4 上下文 token 展示（FR-5 / FR-7）

- [ ] agent 页展示当前会话上下文使用（如「输入 X / 输出 Y tokens」）。
- [ ] 发送多轮后 token 数随对话增长（输入/输出分别累计）。
- [ ] 平台未返回 usage 时显示 0，不报错、不影响对话。

## 回归

- [ ] 搜索、论文分析、创新点、实验方案、上传、Agent、服务器管理均正常。
- [ ] 后端 `pytest tests -q` 全部通过。
- [ ] 前端 `npm run build` 通过。
