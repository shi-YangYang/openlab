# Spec 016 验收清单

## 准备

1. 后端启动、前端启动。
2. 已配置至少一台 SSH 服务器（`data/servers.json`，凭据有效）。

## AC-1 SSH 交互终端（FR-1 / FR-4）

- [ ] 服务器详情页出现「终端」区块，打开后能连上该服务器并显示 shell 提示符。
- [ ] 能执行交互命令（如 `ls`、`pwd`），输出实时回显。
- [ ] 支持交互式程序（如 `vi` 编辑、`python` REPL、`top` 实时刷新），光标/颜色正常。
- [ ] 调整浏览器窗口或终端容器尺寸后，远端 PTY 尺寸同步（`stty size` 反映变化，长行正确换行）。
- [ ] 服务器凭据错误/连接失败时，终端区显示明确错误提示，不崩溃。

## AC-2 连接生命周期（FR-2 / FR-5）

- [ ] 关闭终端组件或点「断开」后，后端释放对应 SSH channel（无泄漏、无残留连接）。
- [ ] SSH 掉线（服务器断开）时前端给出「已断开」提示，可重连。
- [ ] 快速连续开关终端不报错、不残留连接。

## AC-3 安全与兼容（NFR-2 / NFR-4）

- [ ] 终端输入输出含中文/特殊字符不乱码、不崩溃。
- [ ] 后端日志不出现服务器密码/私钥明文。
- [ ] 前端 `npm run build` 通过。
- [ ] 后端全量测试通过（`pytest tests -q`）。

## 回归

- [ ] 搜索、分析、创新点、实验方案、Agent、服务器管理、部署、监控均正常。
- [ ] Vite 开发模式下 WebSocket 经代理正常连接（`ws: true` 已生效）。
