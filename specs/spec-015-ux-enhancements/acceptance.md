# Spec 015 验收清单

## 准备

1. 后端启动、前端启动。
2. 论文库已有若干论文（含可下载的 arXiv 论文与一条 upload 论文）。
3. LLM 已配置（任意 OpenAI 兼容平台）。

## AC-1 内容区宽度（FR-1）

- [ ] 大屏（≥1600px）下内容区最宽约 1600px 且水平居中。
- [ ] 中等视口（如 1366px）下内容区随视口收缩，仍有合理内边距，不横向溢出。
- [ ] 小屏（如 1280px 及以下）下内容区接近满宽但仍保留左右 padding。

## AC-2 历史二级菜单（FR-2 / FR-3）

- [ ] 顶部菜单「历史」鼠标悬浮出现子菜单：搜索历史、创新点历史、实验方案。
- [ ] 点击三个子项分别进入独立页面，URL 分别为 `/history/search`、`/history/innovation`、`/history/experiment`。
- [ ] 原「历史」页内的 Tabs 已移除；直接访问 `/history` 会重定向到 `/history/search`。

## AC-3 实验方案历史（FR-4 / FR-5）

- [ ] 生成若干实验方案后，「实验方案」历史页能列出：时间、来源、语言、状态、方案数。
- [ ] 点击「查看」能弹窗展示方案内容。
- [ ] 点击「导出」能下载 Markdown 文件。
- [ ] 点击「删除」能删除单条并刷新。
- [ ] 后端 `GET /api/experiments` 返回列表；`DELETE /api/experiments/{id}` 生效。

## AC-4 LLM 配置增强（FR-6 / FR-7）

- [ ] 设置页 LLM 配置出现「思考强度」下拉（low/medium/high），可清空。
- [ ] 保存后，`data/llm_config.json` 中含 reasoning_effort 字段。
- [ ] 输入 base_url + api_key 后点「获取模型」，能拉出该平台模型列表并以下拉展示。
- [ ] 模型下拉支持搜索与自定义输入。
- [ ] 不支持的平台点「获取模型」给出明确错误提示，不崩溃。

## AC-5 论文库删除（FR-8）

- [ ] 论文库表格操作列出现「删除」按钮，点击后 Popconfirm 二次确认。
- [ ] 确认后：论文从列表消失，本地 PDF 文件被删除，`/api/papers` 不再返回该论文。
- [ ] 对已无本地 PDF 的论文删除仍成功（幂等）。
- [ ] 搜索页结果表格不出现「删除」按钮。

## AC-6 上传 PDF 来源 URL（FR-9）

- [ ] 上传一个含 arXiv 链接的 PDF，确认表单「来源 URL」预填了分析结果。
- [ ] 上传一个无法推断来源的 PDF，来源 URL 为空，可手动填写。
- [ ] 确认后，论文库中该论文的标题链接/「查看原文」使用填写的来源 URL。

## 回归

- [ ] 搜索、分析、创新点、实验方案、Agent、服务器管理均正常。
- [ ] 后端全量测试通过（`pytest tests -q`）。
- [ ] 前端 `npm run build` 通过。
