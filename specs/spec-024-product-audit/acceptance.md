# Spec 024 验收清单

## AC-1 运行刷新接管（B-1）

- [ ] 发起一次实验运行（训练脚本循环打印）→ 运行中刷新页面 → 重新打开该实验的执行面板 → 自动恢复到运行视图并继续滚动新日志（而非回到创建视图）。
- [ ] 「运行记录」页可随时点详情查看该 run 最新日志。

## AC-2 删除会话终止任务（B-2 / U-4）

- [ ] agent 任务运行中删除该会话：远端/本地任务立即停止，不产生后续写库。
- [ ] 运行中会话的删除确认文案包含「终止任务」警示；空闲会话为普通文案。

## AC-3 级联清理 runs（B-3）

- [ ] 删除某实验方案后，「运行记录」中该方案的 runs 一并消失；日志文件被清理。

## AC-4 下载轮询（B-4 / U-2）

- [ ] 大文件（>100MB）下载超过 3 分钟进度条仍持续更新（或至少结束时状态正确收敛，不再永久停在中间值）。

## AC-5 执行面板健壮性（U-1 / U-3 / U-5）

- [ ] 运行中重启后端：面板出现断线 Alert 并自动重连，恢复后日志对齐。
- [ ] 日志区有「复制日志 / 下载日志」按钮且功能正确。
- [ ] 窄窗口（~1000px）下控件行换行整齐，圆环不被挤压变形。

## AC-6 全局错误边界（E-3）

- [ ] 人为注入渲染错误（dev 环境）时显示错误兜底页与「重新加载」按钮，而非整站白屏。

## 回归

- [ ] 后端 `pytest tests -q` 全部通过；前端 `npm run build` 通过。
- [ ] 论文搜索→下载→分析、agent 流式对话、实验执行主流程正常。
