## 背景与动机

## 范围与需求描述

### Bug 类

- **B-1（高）**：实验执行面板的 `runId` 只存在内存——运行中刷新页面后失联，面板回到创建阶段，而远端任务还在跑（用户以为停了其实还在烧卡）。修复：创建视图下若该实验已有运行中/暂停的 run，自动载入最近一次 run 详情与日志并接管通道；运行记录页可随时重新进入。
- **B-2（高）**：删除 Agent 会话时未停止正在运行的 runner 任务——任务继续跑并在 done 时写库/发事件到已删除会话。修复：`DELETE /api/agent/sessions/{id}` 先调 runner 的 stop/清理，再删会话。
- **B-3（中）**：删除实验方案时其 runs 成为孤儿记录（experiment_id 悬空，面板打开报“实验方案不存在”）。修复：删除实验方案时级联终止并删除其全部 runs（或至少标 orphan 并在 UI 过滤），本期采用级联删除 runs。
- **B-4（中）**：论文批量下载前端轮询有 180 秒硬上限，大 PDF/慢网络下超时后进度条停更但任务实际还在下载。修复：上限延长至 10 分钟，且轮询超时后再静默补拉一次列表对齐真实状态。

### 体验类

- **U-1**：实验执行面板 WS 断开无任何提示与重连——加指数退避重连 + 断线 Alert，恢复后自动重拉日志尾部对齐。
- **U-2**：论文下载轮询超时/结束后不再刷新，改为：轮询结束时统一再拉一次 `/api/papers` 校准全部状态。
- **U-3**：实验执行面板日志区无「复制日志」「下载日志」按钮——排查问题需要带走完整日志。两个按钮加在日志区头部。
- **U-4**：会话删除前如正在运行，直接删会丢任务——Popconfirm 文案区分「会话正在运行，删除将同时终止任务」。
- **U-5**：Agent 页「模型/思考强度/上下文圆环」在窄屏会挤压换行错位——改为 flex wrap 且圆环固定尺寸。

### 工程类

- **E-1**：SQLite 无 WAL 模式，长事务与并发读（agent 流式写 + 前端轮询读）偶发 `database is locked`。修复：`_connect` 统一开启 WAL + busy_timeout。
- **E-2**：`papers.arxiv_id` 已有唯一索引但查询热点（按 source、status 过滤）无索引——为 `papers(source)`、`papers(status)` 建索引（_migrate 幂等创建）。
- **E-3**：前端无 ErrorBoundary，任一组件渲染崩溃即整站白屏（本次已实际发生）。修复：main.tsx 包一个全局 ErrorBoundary，崩溃时显示错误信息 + 「重新加载」按钮。

### 非功能需求

- NFR-1：所有新测试通过；`pytest tests -q` 与 `npm run build` 全绿。
- NFR-2：不改既有 WS 协议字段，仅新增事件。
