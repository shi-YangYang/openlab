# Spec 025 验收清单

## AC-1 上传文件

- [ ] Agent 页输入框左下角有「+」按钮，点击弹出菜单（添加文件 / 添加文件夹）。
- [ ] 「添加文件」选单个/多个文件后上传成功，输入框上方出现 Tag 列表显示文件路径。
- [ ] 上传完成自动向 Agent 发送提示消息，助手气泡确认已收到文件列表。
- [ ] 后续对话让 Agent 读取该文件内容，Agent 能正确输出。

## AC-2 上传文件夹

- [ ] 「添加文件夹」选择一个本地文件夹，所有文件（含子目录层级）上传成功。
- [ ] Tag 列表显示相对路径（含目录层级），Agent 可按路径读取。

## AC-3 错误处理

- [ ] 未发消息直接上传（无会话）：提示「请先发送消息创建会话」。
- [ ] 路径穿越攻击（path 含 ../）被拒绝。

## 回归

- [ ] Agent 对话/审批/停止/导出正常；沙箱清理跟随会话删除不变。
- [ ] 后端 `pytest tests -q` 全部通过；前端 `npm run build` 通过。
