# 验收标准与验收记录：Agent 核心（spec-010）

## 验收标准

- AC-1（对应 FR-1）：封装全量工具（文献/分析/服务器三类齐全）。
- AC-2（对应 FR-2）：agent 能自主调用工具完成多步任务（如「搜索 X 并分析」）。
- AC-3（对应 FR-3）：任务式（给目标）与对话式都能工作。
- AC-4（对应 FR-4）：多轮对话通过 session 关联历史。
- AC-5（对应 FR-5）：`POST /api/agent/chat` 返回回复 + 工具调用日志。
- AC-6（对应 FR-6）：前端 Agent 页面有输入/对话/工具日志/进度。
- AC-7（对应 FR-7）：工具调用日志展示工具名、参数、结果摘要。
- AC-8（对应 NFR-2）：密钥不入库、不打印、脱敏。
- AC-9（对应 NFR-3）：慢工具等待/超时保护，不无限阻塞。
- AC-10（对应 FR-8）：危险工具（run_command/deploy_code）调用前暂停并返回待确认，确认前不执行。
- AC-11（对应 FR-9）：`POST /api/agent/approve` 确认后执行、拒绝后跳过并反馈 agent。

## 验收步骤

1. 启动后端与前端。
2. Agent 页给一个任务（如「搜索注意力机制相关论文并分析前 2 篇」），观察工具调用日志与结果。
3. 对话式追问，观察多轮会话。
4. 给一个部署/监控类任务，观察服务器工具调用。
5. 运行 pytest 通过。
