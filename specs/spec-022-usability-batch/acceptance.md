# Spec 022 验收清单

## 准备

1. 后端、前端启动；论文库含已下载与未下载论文；有历史 agent 会话。

## AC-1 分析按钮状态（FR-1）

- [ ] 论文库中未下载论文的「分析」按钮灰显，悬浮提示「请先下载该论文」。
- [ ] 已下载论文按钮正常可用；百度学术来源不显示「分析」按钮（既有行为不变）。

## AC-2 上传重复提示（FR-2）

- [ ] 同一 PDF 文件第二次上传确认后出现 warning 提示，主流程不中断，记录照常入库。
- [ ] 全新文件上传无该提示。

## AC-3 配置组刷新联动（FR-3）

- [ ] 设置页修改当前使用组并保存后，进入 Agent 页：模型下拉已是新组的模型列表，思考强度选项同步更新。无需刷新页面。

## AC-4 时间戳（FR-4）

- [ ] 用户消息右下角、assistant 消息底部显示 HH:mm 时间，样式次要色 12px 不喧宾夺主。

## AC-5 分页可调（FR-5）

- [ ] 论文表格分页可切换 10/20/50/100 每页；搜索结果页同样生效。

## AC-6 中断语义（FR-6）

- [ ] 中断任务的会话在列表中显示橙色「已中断」Tag。
- [ ] 停止后页面弹『任务已中断』info 提示，输入框 placeholder 明确「可继续发送新指令」。

## AC-7 失败工具默认展开（FR-7）

- [ ] 让 agent 触发一个会失败的工具调用（如查不存在的东西）：该工具卡片默认展开显示参数与错误；成功项仍折叠。

## AC-8 危险命令展示（FR-8）

- [ ] 触发 run_shell_command 类危险操作：审批弹窗顶部大号等宽展示命令原文，JSON 参数折叠其下（默认收起）；非命令类工具维持 JSON 展示。

## AC-9 一键重试（FR-9）

- [ ] 分析失败后 Alert 内点「重试分析」以相同语言重新发起。
- [ ] 综述失败后可点「重试综述」重新发起。

## AC-10 历史过滤（FR-10）

- [ ] 搜索历史页头部有关键词过滤框，输入即时过滤。
- [ ] 实验方案历史页同上，可按来源/语言过滤。

## 回归

- [ ] 搜索→下载→分析全流程正常；agent 对话、审批、停止、导出均正常。
- [ ] 后端 `pytest tests -q` 通过；前端 `npm run build` 通过。
